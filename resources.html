Quick guide

How to use the library

Choose fewer resources and use them more deliberately. A simple system is usually easier to maintain.

Use a textbook when you need a structured sequence and enough explanation to build a topic from the beginning.

Documentation works best when you know the concept and need exact syntax, parameters or current standards.

Choose one main source, one practice source and one reference source. Finish a study block before adding another resource.
